# 整理工具下拉栏规划

> 状态：**已实施（2026-09-12，与方向改定同批）**。原「不常用功能工具箱收纳」方向（激活式工具箱面板，2026-09-06 提出）经用户复议**废弃**：实际功能数量并不多，问题只是顶栏 Tools 菜单很久没有经过合适的重排版——改为对 Tools 下拉菜单本身做一次整理即可，无需新增任何收纳容器。

## 一、方向

只重排顶栏 Tools 下拉菜单（`ui/mainwindowbars.py` 的 `toolsMenu` 构建段）：按使用场景重新分组、调整条目顺序与归属，不改任何功能的实现与交互。

**最终分组（已落地）**：

1. 文字/样式工具：样式管理器、Quick Symbol、高级对齐、整理换行（整理换行从「导出/批量处理」并入——它本质是文字清理）
2. 页面/图像工具：区域合并、路径重排、无字图配对（无字图配对从「外部工具」并入——它并非外部工具；「外部工具」分组取消）

## 二、边界与耦合

- **与撤销体系无耦合**：纯入口层重排，命令层（`ui/textedit_commands.py` 等）不动；撤销阶段4第二批的确认弹窗按命令归属照常生效。
- **不做激活式工具箱**：原方向要求的「激活即用、就地呈现参数」容器不再规划；各功能保持现有对话框/交互形态。
