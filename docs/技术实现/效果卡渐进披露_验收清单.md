# 效果卡渐进披露 验收清单（2026-09-08 批次）

本批把常驻描边行整体退役、描边改回独立效果卡，并给所有效果卡加「高级」折叠子层。下面用编号列出每张卡当前每个参数的归属，**请按编号给反馈**。

## 怎么反馈

每个参数都有 ID（`S3`、`SH6`、`G4` …）。想挪动就写「SH6 → 常显」，想换文案写「SH2 改叫 X」，想整卡重排写「阴影卡高级项收成一行」。也可以直接改下面表格里的「当前」列，我按改动落地。

## 全局行为（请逐项确认）

- [ ] 折叠行位于卡片参数区最底部，20px 高，chevron + 「高级」文案
- [ ] 默认收起、**不记忆**（卡片每次重建都回到收起，按你的拍板）
- [ ] 折叠行右侧有一个小圆点：高级项里有非默认值时点亮，收起状态也能看出卡里改过东西
- [ ] 只有存在高级项的卡才显示折叠行；滤镜卡参数全部常显，没有折叠行
- [ ] 折叠行不占独立行间距，与上方参数区同为 8px 间距

## 我拿不准的格子

- **SH6 / G4 不透明度**：收进高级是为了让「每卡常显 = 类型 + 几何 + 颜色」这条规则统一；但它是阴影/发光的强度旋钮，常显更顺手。要改就这两格一起改。
- 描边位置（上表 S2）我本来按计划文档的「只露宽度/颜色」收进了高级，但离屏渲染核对时发现宽度行右半空着很难看，且上游布局本来就是「位置 + 宽度」同行，故提到常显。若你几乎不切位置，可以再降回高级（那行会留一个空位，或者把宽度控件拉满整行）。

## 本批次顺带的连带改动（请一并确认）

1. 常驻描边行删除；`ui/text_panel.py::FontFormatPanel` 里与描边同行的「行距类型」下拉现在是独立一行。
2. 设置面板的「描边宽度」预设行删除，`utils/config.py::ProgramConfig` 的 `stroke_width_presets` 字段一并移除（描边宽度改由卡片内的拖拽数值框输入）。
3. 描边取色即视为手动覆盖：卡片里挑过颜色后，改字色不会再被自动反色冲掉。自动跟随机制本身保留，设置面板开关不变；未手动挑色时仍按字色反色。
4. 加描边的路径从「点常驻宽度框」变成「Add → 描边」两次点击，新加的描边默认宽度 0.1（落地即见）。
5. 描边编辑的撤销条目名从「Format: Stroke Width」变为「Text Effect」（效果栈命令的统一名）。若要保 PS 式操作名，需要另给效果命令加细化名，不在本批。
6. 描边卡保留渐变能力（Fill 类型可切渐变）。描边为渐变时改字色不再自动反色——已按「取色即手动覆盖」处理。
7. 卡片的删除按钮对描边卡 = 从栈里删掉描边条目（宽度随之归 0、卡片消失）。若你希望它等价于「宽度归零但保留卡片」，说一声。

## 存量工程影响

老工程里的描边不会丢：`utils/fontformat.py::_migrate_legacy_text_effects` 会把旧的 `stroke_width`/`srgb` 字段迁移成等价的栈条目，加载后直接以描边卡出现。

## 首轮实机反馈修复（2026-09-08）

1. **特效区取色器一调色就崩**：`ui/text_engine/effects/gradient_editor.py` 补回移植时漏掉的 `_replaced_selected_stop`（上游有，fork 只剩调用点；渐变编辑器此前被永久隐藏，所以一直没暴露）。现在渐变停点取色的实时预览正常。
2. **色块压住其他功能项**：`ui/text_engine/effects/cards.py::_set_effect_selector_width` 的 `Ignored` 策略向布局上报零宽度，与 stretch 色块同行时色块被排在它头上。改为 `Preferred` 后布局正确让位（Fill 行现在是「下拉 + 色块」并排）。
3. **下拉双箭头**：自绘 chevron 的控件没关原生箭头。`ui/custom_widget/combobox.py::BottomBorderComboBox` 补 `bottomBorderSelector` 属性 + `config/stylesheet.css` 对应 `::down-arrow { image: none }`；`TextEffectBlendSelector` 补 `::menu-indicator { image: none }`。现在每处只有一个箭头。

以上三条已加回归测试（`tests/test_text_effects_cards.py`），离屏渲染核对通过。

## 第二轮实机反馈修复（2026-09-08）

1. **折叠栏的关闭按钮删除**：`ui/custom_widget/view_panel.py::ExpandLabel` 新增 `hide_button` 开关（`PanelArea`/`ViewWidget` 透传），`ui/text_engine/effects/panel.py::TextEffectPanel` 关闭它。该按钮只是把面板 `setVisible(False)` 并写 `pcfg.show_text_effect_panel=False`，在效果区没有实际意义。
2. **描边凭空生成**：`utils/fontformat.py::FontFormat` 的旧字段活体写入不再创建描边——写 `srgb`（自动反色跟随字色）只在已有描边时改色，写 `stroke_width` 为 0 且无描边时直接忽略；只有真正设了非零宽度才会新建。渲染侧 `FontFormat.effective_stroke_color` 本来按前景色反色派生，不依赖这份存档。
3. **Add → 描边 无响应**：`ui/text_engine/effects/panel.py::TextEffectPanel` 的白名单漏了 `'stroke'`（上一批退役描边卡时删的，菜单项恢复时没同步），已补。
4. **效果卡数值框改 Blender 式拖拽**：`ui/text_engine/effects/cards.py::EffectNumericControl` 现在在数值框上横向拖动调值（悬停 ↔ 光标 + 背景提亮、Shift 精调、单击进文本编辑），沿用同一套 DRAG_PREVIEW 状态机——拖动中实时预览、松手提交一次，撤销语义不变；标签退为纯描述文本（`ui/text_engine/transforms/panel.py::TransformDragLabel` 加 `drag_enabled` 开关，变换面板仍是标签拖拽）。
5. **无单位参数上限压到 1**：新增 `utils/text_effects.py::EFFECT_MAGNITUDE_LIMIT`，描边宽度、阴影距离/模糊/扩散、发光大小/扩散的卡片上限统一为 1（百分比/px/角度不受影响）。校验上限仍是 10，旧工程里存有更大值不会被加载时丢弃；滤镜参数沿用 %/px 约定（`ui/text_engine/effects/filters/filter_grain.py` 的 Size 补上 ` px` 后缀），已用测试钉住「无单位浮点参数上限 ≤ 1」这条不变量。

## 第三轮实机反馈（2026-09-08 收尾）

1. **取色器补 alpha 通道**：`ui/custom_widget/color_picker.py::ColorPickerDialog` 新增 `alpha=True` 模式——顶部多一条纵向 alpha 滑条（棋盘底 + 透明→不透明渐变），数值列多一行 A（0–100%），新旧色预览铺棋盘底；关闭时行为与旧版完全一致（始终不透明 RGB）。渐变停点没有独立的不透明度数值框（fork 早先精简掉了），现在改由取色器 alpha 承担：`ui/text_engine/effects/gradient_editor.py::InlineLinearGradientEditor` 打开停点取色时带上当前 `stop.opacity`，实时预览把 alpha 写回 `GradientStop.opacity`；停点色块也铺棋盘底，半透明停点一眼可见。
2. **描边自动反色改为「添加时检测一次」**：放弃改字色实时联动，改在添加描边时按当前文字色取反色作为初始描边色并标记为手动（`ui/text_engine/effects/edit_session.py::TextEffectEditSession`），此后描边色不再随字色变化。设置面板的全局开关同步改为控制这次初始反色，文案与说明已更新。
